# .ai/sessions — Bitácora de sesiones con agentes de IA

Cada tarea completada con un agente deja una entrada aquí:

    <YYYY-MM-DD>/<HHMM>-<slug>.md

Contenido mínimo (ver `AGENTS.md` §8):

- Herramienta, modelo, versión.
- Hash del commit resultante (o "sin commit").
- Prompt original del humano (texto literal).
- Plan ejecutado (resumen).
- Suposiciones asumidas y riesgos.
- Resultado de typecheck, lint y tests.

**Este directorio se versiona**: es la fuente de verdad para auditoría.
