El sensor IAST interceptó la llamada a crypto.createHash('md5') dentro del paquete externo winston-daily-rotate-file. El algoritmo es invocado exclusivamente para generar identificadores y nombres de archivos de texto rotativos en disco (ej. app-2026-11-16.log).
Verificación de Seguridad: Las contraseñas de la base de datos utilizan Argon2 / Bcrypt con salt criptográfico fuerte, y los tokens de sesión utilizan JWT HMAC-SHA256 (HS256) con secreto rotado. No existe riesgo de colisión ni exposición de credenciales.
